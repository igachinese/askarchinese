# Личный кабинет Аскара

Статический сайт на GitHub Pages, без сборки.

- `index.html` — кабинет, расписание, баланс и история отчётов.
- `trainer.html`, `practice.css`, `practice.js` — единый центр практики и игр.
- `games.html` — совместимая старая ссылка: открывает раздел игр в центре практики.
- `speech.js` — общая озвучка: Xiaoyi / 晓伊 первым, выбор другого китайского голоса, скорость 0,65 или 0,70. Голоса предоставляет браузер/ОС. При недоступной озвучке слуховой раунд не запускается, доступны текстовые задания.
- `data/askar.json` — исходные 20 тем и 249 уникальных слов.
- `data/hanzi-strokes.json` — локальные схемы 252 иероглифов словаря; загрузка только при открытии письма.
- `vendor/` — Hanzi Writer 3.5.0 и лицензии.

Прогресс упражнений сохраняется на устройстве в `askar.practice.v2`; настройки озвучки — в `askar.speech.v2`. Ошибочное слово попадает в повторение и уходит из него после двух правильных ответов подряд. Самооценка карточек не повышает число проверенных правильных ответов.

Расписание хранится в JSON-блоке `dashboard-data` кабинета. `done` — проведён, `planned` — оплачен/запланирован, `cancelled` — отменён без списания. Оплаченные даты: 15, 22, 29 ноября, 6 и 13 декабря 2026; воскресенье 17:00 МСК / 19:00 Астана. Сами даты не списывают занятия автоматически. При изменении баланса обновляйте журнал и карточку баланса вместе.

Грамматика: короткие фразы заданы в `GRAMMAR` в `practice.js`. Если для темы ещё нет отдельных фраз, интерфейс явно предлагает базовые фразы для диалога.

Проверки из корня репозитория:

```sh
node tests/practice.cjs
node tests/speech.cjs
```

Публикация: обычный коммит в `main`, далее штатная сборка GitHub Pages.


## Иллюстрации тем · ноябрь 2026
В assets/topics/ — отдельная WebP-иллюстрация каждой словарной группы (имя файла = ID темы). Карточка темы и заголовок выбранной темы используют эту иллюстрацию. Изображения сгенерированы в стиле Chinese Storybook Ink & Wash, без текста; палитра соответствует кабинету ученика.
